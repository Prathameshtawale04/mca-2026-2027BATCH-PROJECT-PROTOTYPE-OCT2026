Academic Methodology & Configuration

Face Detection: Frontal Haar feature-based cascade classifier detects facial bounding box (x, y, w, h). The ROI is converted to grayscale, resized to 200×200 pixels, and normalized using histogram equalization.

LBPH Recognizer: Uses cv2.face.LBPHFaceRecognizer_create(radius=1, neighbors=8, grid_x=8, grid_y=8). Computes 64 spatial histograms concatenated into a feature vector.

Confidence Interpretation: LBPH returns a Euclidean distance metric. Distance ≤ 70.0 is classified as authentic. Match confidence percentage is derived as: Confidence = max(0, min(100, (1 - distance / 120) * 100)).
