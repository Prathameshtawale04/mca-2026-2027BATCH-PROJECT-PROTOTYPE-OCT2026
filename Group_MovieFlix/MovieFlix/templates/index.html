Frequently Asked Questions

MovieFlix is an intelligent movie discovery and recommendation platform built as a data science capstone project. It combines full-bleed Netflix cinematic streaming aesthetics with academic-grade Information Retrieval (IR) algorithms.

MovieFlix converts rich metadata (titles, plot overviews, genres, thematic keywords, directors, and actors) into a 7,500-dimensional TF-IDF vector space. It calculates the Cosine Similarity angle between high-dimensional document vectors to identify nuanced thematic and stylistic alignments in sub-3 milliseconds.

Cosine similarity evaluates the inner dot product of two L2-normalized feature vectors: cos(θ) = (u · v) / (||u|| ||v||). This ensures recommendations remain unbiased by document length, focusing purely on semantic orientation.

The backend is built with Python 3.13 and Flask, backed by MySQL 8 (with automated SQLite fallback). Machine learning models use Scikit-Learn and Scipy sparse CSR matrices. The frontend is vanilla HTML5, CSS3, and JavaScript with zero heavy dependencies.
